# StudyFlow – Student Academic Management System

StudyFlow là ứng dụng quản lý học tập cá nhân dành cho sinh viên đại học, hỗ trợ theo dõi kết quả học tập, tính GPA, quản lý thời khóa biểu và lập kế hoạch học tập.

## Chức năng chính

1. **Dashboard:** Hiển thị GPA hiện tại, số tín chỉ tích lũy và số môn đang học.
2. **Quản lý học kỳ và môn học:** Quản lý năm học, học kỳ, môn học, tín chỉ, giảng viên và trạng thái môn học.
3. **Quản lý điểm và GPA:** Nhập điểm thành phần, tính điểm tổng kết, điểm chữ, GPA học kỳ và GPA tích lũy.
4. **Thời khóa biểu:** Quản lý lịch học theo thứ và tiết học.
5. **Bài tập và To-do:** Quản lý bài tập theo môn học, deadline, mức ưu tiên, trạng thái, công việc con và tiến độ.
6. **Thống kê và GPA Planner:** Biểu đồ GPA, tín chỉ tích lũy, tỷ lệ hoàn thành bài tập và tính điểm cần đạt để đạt GPA mục tiêu.

## Công nghệ dự kiến

- Backend: Node.js, Express.js, TypeScript
- Database: PostgreSQL
- ORM: Prisma
- Authentication: JWT
- Web: React, TypeScript
- Mobile: React Native, Expo
- API: REST API

## Cấu trúc dự án

- `backend/`: Backend và REST API
- `web/`: Ứng dụng Web
- `mobile/`: Ứng dụng Mobile
- `docs/`: Tài liệu phân tích và thiết kế
